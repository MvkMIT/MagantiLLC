# Maganti Group - Modern IT Solutions Website

A modern, responsive website built with Next.js 13, TypeScript, and Tailwind CSS showcasing Maganti Group's IT solutions and leadership team.

## 🚀 Features

- **Modern Design**: Clean, contemporary UI with glassmorphism effects
- **Responsive Layout**: Mobile-first design that works on all devices
- **Interactive Elements**: Smooth hover animations and transitions
- **Team Showcase**: Leadership team with photos and roles
- **Service Sections**: Expertise areas and technology innovations
- **Career Opportunities**: Jobs section with statistics
- **Contact Integration**: CTA section with contact information

## 🛠️ Tech Stack

- **Framework**: Next.js 13 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI with shadcn/ui
- **Icons**: Lucide React
- **Deployment**: Netlify

## 🎨 Design System

### Color Palette
- **Primary Blue**: `#2563eb` (blue-600)
- **Secondary Cyan**: `#06b6d4` (cyan-600)
- **Dark Slate**: `#0f172a` (slate-900)
- **Light Gray**: `#f8fafc` (slate-50)

### Typography
- **Headings**: Font-bold, tight tracking
- **Body**: Font-light, relaxed leading
- **Buttons**: Font-medium, rounded corners

### Effects
- **Glassmorphism**: Backdrop blur with transparency
- **Hover Animations**: Scale, translate, rotate effects
- **Gradients**: Blue to cyan color transitions
- **Shadows**: Multi-layered shadow system

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn package manager

### Installation
```bash
# Clone the repository
git clone https://github.com/MvkMIT/MagantiLLC.git

# Navigate to project
cd MagantiLLC

# Install dependencies
npm install

# Start development server
npm run dev
```

### Available Scripts
```json
{
  "dev": "Start development server",
  "build": "Build for production",

}
```
